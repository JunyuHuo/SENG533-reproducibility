# Figure provenance

All nine data plots are generated by `analysis/plot.py` from `data/runs.csv`.
The committed PDF files are the vector graphics used by the paper; PNGs provide
convenient previews. `plot-data.csv` records every plotted mean, sample standard
deviation, sample count, and unit conversion (124 rows).

| Paper graphic | File(s) | Calculation |
| --- | --- | --- |
| Experimental architecture | First page of `diagrams.tex` | Editable conceptual TikZ diagram; no experimental data |
| Launch workflow | Second page of `diagrams.tex` | Editable conceptual TikZ diagram; no experimental data |
| Baseline throughput, read/mixed/write | `image9`, `image5`, `image10` | Mean of 3 launches; error bars are sample SD; kops/s |
| Baseline response time, read/mixed/write | `image8`, `image4`, `image6` | Mean of 3 launch-level operation-weighted means; milliseconds; log y-axis |
| Matched memory upgrade throughput | `image12` | Mean of 3 runs on each server size; kops/s |
| Matched read p99 | `image11` | Mean of 3 run-level p99 values, not a pooled percentile; milliseconds; log y-axis |
| Matched resource utilization | `image2` | Mean of 3 run-level measurements; percent |

The four matched configurations, in plotting order, are Cassandra read-heavy
at 64 threads, Cassandra write-heavy at 128, MongoDB read-heavy at 64, and
MongoDB write-heavy at 1. The resource figure abbreviates these as Cas. read,
Cas. write, Mongo read, and Mongo write.

To regenerate data figures:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-figures.txt
python analysis/plot.py
```

Outputs are in `build/figures/`. To regenerate the two-page conceptual diagram
PDF, use a TeX installation with `standalone` and TikZ:

```sh
mkdir -p build
pdflatex -halt-on-error -output-directory=build figures/diagrams.tex
```

The paper embeds these two TikZ environments directly. Raster font rendering can
vary between platforms; the plotted quantities and vector geometry are derived
from the same source. The earlier report's chart styling has been refreshed for
readability without changing the observations or aggregation method.
